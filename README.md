# 古今标点文脉馆

> 数字展览 · 博物馆主屏交互系统  
> 上海图书馆「全国报刊索引」开放数据竞赛参赛作品

---

## 一、作品简介

《古今标点文脉馆》是一个以"标点演变"为主线、串联古典与近代文学资源的创意性数字展陈方案。它以"标点"这一承载语义、节奏与时代审美的书写符号为入口，从先秦无标点到民国新式标点，系统呈现标点在中国文学中的演变脉络。

### 核心展项

| 展项 | 功能 |
|------|------|
| **索引档案** | 调用全国报刊索引开放接口，检索 1833 年至今的中文报刊文献元数据 |
| **AI 标点展演** | 将文本转写为五种时代标点风格（先秦/唐宋/明清/民国/通典） |
| **名家风格馆** | 选择李白、杜甫、鲁迅等 12 位中外名家，按其实写作风格生成标点诗文 |
| **雕版复刻** | 上传古籍图片，叠加朱笔圈点、眉批与馆藏印章，再现古人读书批注样貌 |

## 三、部署与运行步骤

### 方式一：一键启动（推荐）

```bash
# 进入项目目录
cd gujin-biaodian

# 启动服务（默认端口 8000）
python server.py
```

启动后在浏览器打开 **http://localhost:8000** 即可访问。

### 方式二：自定义端口

修改 `server.py` 第 10 行的 `PORT` 变量：

```python
PORT = 8080   # 改为你需要的端口
```

### 可选：启用在线大模型（AI 标点展演增强）

项目内置了本地标点样式引擎，离线即可使用。如需接入在线大模型获得更好的生成效果，配置以下环境变量：

```bash
# 方式一：DeepSeek（默认已内置可用 Key，也可用自己 Key）
set DEEPSEEK_API_KEY=你的DeepSeek_API_Key

# 方式二：OpenAI
set OPENAI_API_KEY=你的OpenAI_API_Key
set OPENAI_BASE_URL=https://api.openai.com/v1/chat/completions

# 方式三：Azure OpenAI
set AZURE_OPENAI_API_KEY=你的Azure_Key
set AZURE_OPENAI_ENDPOINT=https://你的资源名.openai.azure.com
set AZURE_OPENAI_DEPLOYMENT=你的部署名
```

> **注意**：不配置在线大模型也能完整使用所有功能，系统会自动回退到本地标点样式引擎。

## 四、使用数据说明

### 4.1 全国报刊索引开放数据

本项目通过上海图书馆「全国报刊索引」开放数据接口实时检索文献元数据：

- **数据接口**：`https://data.cnbksy.com/competitionSearch`
- **数据范围**：1833 年至今的中文报刊文献
- **返回字段**：题名、作者、刊名、年份、卷期、页码、摘要、关键词、中图分类号等
- **检索方式**：支持按题名(TI)、刊名(JTI)、全文(ALL)三种模式检索，可指定起止年份
- **API Key**：已内置竞赛用 Key，也可通过环境变量 `CNBKSY_API_KEY` 配置

### 4.2 本地数据

| 数据 | 位置 | 说明 |
|------|------|------|
| 诗人标点风格库 | `app.js` 第 9-94 行 | 12 位中外名家的标点习惯与示例诗文（人工整理） |
| 时代标点规则 | `app.js` 第 184-215 行 | 五种时代的标点转换规则 |
| 雕版示范内容 | `app.js` 第 522-531 行 | 雕版复刻示范文字（原创编写） |

### 4.3 图片资源

`通典500-999/` 目录包含 500 张古籍雕版图片，因体积较大（约 2.25 GB），未纳入 Git 仓库。如需使用，请从本地备份恢复至项目根目录下。

## 五、创作流程与提示词工程

### 5.1 整体架构

```
┌──────────────┐    HTTP/API    ┌──────────────┐    HTTPS    ┌─────────────────┐
│  index.html  │ ◄────────────► │  server.py   │ ◄─────────► │ 全国报刊索引 API  │
│  app.js      │   端口 8000     │  (代理层)    │            │ data.cnbksy.com  │
│  styles.css  │                │  路由+转发   │            └─────────────────┘
└──────────────┘                │              │    HTTPS    ┌─────────────────┐
                                │  LLM 代理    │ ◄─────────► │ DeepSeek /       │
                                │  /api/llm    │            │ OpenAI / Azure   │
                                └──────────────┘            └─────────────────┘
```

### 5.2 标点风格生成逻辑

前端的 `transformText()` 函数（`app.js` 第 184-200 行）实现五种时代的标点规则：

| 时代 | 规则 | 效果 |
|------|------|------|
| 先秦无标点 | 去除所有标点，纯文字连排 | 模拟先秦简帛阅读感 |
| 唐宋句读 | 每个标点后换行 | 重建诵读停顿节奏 |
| 明清圈点 | 添加句号收束全段 | 模拟圈点终止感 |
| 民国新式标点 | 标点后加半角空格 | 近代报刊清晰排版 |
| 通典断句 | 标点后换行 + 史观断制 | 500-999 年代窗口风格 |

### 5.3 在线大模型调用（提示词工程）

当配置了在线大模型时，`server.py` 第 215-247 行构造以下 System Prompt：

```
你是一个精通中国古典文学与现代写作的 AI 助手，你的任务是以特定时代/人物的标点风格改写文字。
```

- **时代模式**：根据 `mode` 参数（pre-qin / tang-song / ming-qing / modern / tongdian）构造相应提示词
- **名家模式**：根据 `poet` 和 `habit` 参数动态注入该作家的标点习惯描述
- **回退机制**：大模型不可用时自动切换本地规则引擎

### 5.4 雕版复刻算法

Canvas 2D 绘制流程（`app.js` 第 471-633 行）：

1. 绘制仿古纸底色 + 帘纹纹理
2. 双层书页边框（外粗内细）
3. 版心标题 + 装饰分隔线
4. 正文竖排模拟
5. 伪随机散布朱笔圈点（`b33a2f` 红色，含外圈句读 + 旁点语气）
6. 右下角「文脉馆藏」印章
7. 若用户上传图片，则在图片上叠加半透明纸色 + 圈点 + 印章

## 六、人工干预环节

本项目在以下关键节点引入了人工干预，确保内容的学术严谨性与文化表达的准确性：

| 环节 | 人工干预内容 | 位置 |
|------|-------------|------|
| **诗人标点习惯** | 12 位名家的标点风格描述由人工查阅文献后提炼撰写，非 AI 生成 | `app.js` 第 9-94 行 |
| **时代标点规则** | 五套标点转换规则基于文学史与版本学研究成果人工定义 | `app.js` 第 184-215 行 |
| **雕版示范文字** | 雕版复刻示范页面的正文由人工原创编写 | `app.js` 第 522-531 行 |
| **前端文案** | 页面所有引导文字、展项说明、接口提示由人工撰写 | `index.html` 各处 |
| **方案文档** | `方案二_古今标点文脉馆.md` 由人工独立完成 | 项目根目录 |
| **大模型输出审核** | 在线大模型生成结果标注了 Provider 来源，保留人工核验入口 | |
